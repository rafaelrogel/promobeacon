🚀 Getting Started & Flashing Guide
🔌 Hardware Connection & 1-Click WebSerial Flasher ▼

PromoBeacon supports all standard ESP32 development boards (ESP32-C3, ESP32-S3, ESP32 classic). Flashing requires zero command-line tools—it runs 100% in your browser via the WebSerial API.

Step-by-Step Installation:

  1. USB Cable Type: Connect the ESP32 to your PC using a USB Data Cable (verify it is not a charge-only cable).
  2. Browser Requirements: Open this website in Google Chrome, Microsoft Edge, or Opera on desktop (Safari and Firefox do not support WebSerial).
  3. Drivers: Most modern Windows/macOS systems recognize the board automatically. If your serial port does not appear, install the CP210x Driver or WCH CH340 Driver.
  4. Click "Start Installation": Switch to the USB Flasher tab, select your COM port, and click Connect.
  5. Clean Install (Recommended): Check the "Erase Device" option to format the flash cleanly and provision the 2.7MB BigStorage partition.
Troubleshooting Stuck Flashing ("Failed to connect"):
Some ESP32-C3 boards require manual bootloader entry: press and hold the BOOT button, tap the RESET (RST/EN) button once, and release BOOT. Then click Connect in your browser.
✨ First Boot & Initial Configuration ▼

Once flashed, the ESP32 reboots immediately and begins broadcasting its default open Wi-Fi network:

  • Default SSID: PROMOBEACON
  • Security: Open (No password required)
  • Gateway IP: http://192.168.4.1/
  • Default Admin Password: 12345

To configure your campaign, connect any smartphone, tablet, or laptop to PROMOBEACON. The captive portal popup will trigger automatically. You can also visit http://192.168.4.1/setup in your browser to change the SSID, set promotional text, or update regulatory domain settings.

📁 Asset Architecture & Media Management
📦 Complete Guide: Storing Images, PDFs, and Files in /assets/ ▼

PromoBeacon is completely autonomous: it does not use the internet or cloud hosting. All content delivered to nearby customers lives inside the ESP32's internal 2.7 MB BigStorage flash memory.

1. How Asset Routing Works:

When a customer smartphone visits your portal and requests an asset, the ESP32 web server resolves the path seamlessly:

Requested URL in HTML Internal Storage Path MIME Type Returned Status
/assets/menu.pdf /storage/assets/menu.pdf (or /storage/menu.pdf) application/pdf Recommended
/assets/hero.jpg /storage/hero.jpg image/jpeg Supported
/assets/style.css /storage/style.css text/css Supported
/assets/icon.svg /storage/icon.svg image/svg+xml Supported

2. How to Upload Files to the Beacon:

  • Method A — Built-in Web Manager: Connect to the beacon's Wi-Fi, open your browser, and navigate to http://192.168.4.1/upload. Enter your admin password (default 12345), select your PDF or image, specify the filename (e.g. menu.pdf), and click Upload.
  • Method B — No-Code Visual Builder: In the No-Code Builder tab above, choose your PDF flyer or image. The builder will automatically pack it into your campaign bundle.
  • Method C — REST API (cURL): Developers can upload files via terminal using the command below:
# Upload a PDF menu via cURL (connected to PromoBeacon Wi-Fi): curl -X POST "http://192.168.4.1/upload?name=menu.pdf" \ -H "X-Admin-Pwd: 12345" \ -H "Content-Type: application/pdf" \ --data-binary "@./cardapio.pdf"
Media Size Best Practices:
• Compress PDFs using online tools (SmallPDF, Ghostscript) to keep them between 150 KB and 800 KB for instantaneous downloads.
• Convert photos to WebP or JPEG (80% quality, max width 1080px).
• Inline small icons as SVGs directly into the HTML to save HTTP requests!
🚫 The Zero-Dependency Offline Rule (Why External CDNs Fail) ▼

CRITICAL: Because the PromoBeacon Wi-Fi is an isolated local network with no internet connection, any external link will FAIL:

  • ❌ <link href="https://fonts.googleapis.com/css2..."> → Fails (phone will wait 30 seconds for DNS timeout).
  • ❌ <script src="https://cdn.jsdelivr.net/..."> → Fails (script never loads, breaking page layout).
  • ❌ <img src="https://mysite.com/photo.jpg"> → Fails (broken image icon displayed).

The Native Font Solution:

Use modern native system font stacks. They look beautiful, load in 0.0 milliseconds, and match the user's OS perfectly:

body { font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif; line-height: 1.5; margin: 0; padding: 0; }

Use our Verifier & Linter tab to scan your HTML before deployment. It will flag external dependencies and auto-fix them with a single click.

📡 Captive Portal Engine & OS Compatibility
⚡ How the Auto-Popup Trigger Works (Android, iOS & Windows) ▼

PromoBeacon implements a carrier-grade dual-layer captive detection engine:

1. DNS Wildcard Mirror (UDP Port 53)

The firmware runs an ultra-fast DNS daemon that intercepts all domain name queries (e.g. google.com, apple.com, facebook.com) and immediately answers with the beacon's IP address: 192.168.4.1.

2. RFC Multi-OS Probe Interceptors:

  • Google Android (Android 10 to 14+): Intercepts /generate_204, /gen_204, and RFC 8908 /portal.json. Instead of returning HTTP 204 (No Content), it responds with HTTP 302 Redirect to http://192.168.4.1/, triggering the "Sign in to Wi-Fi" system notification immediately.
  • Apple iOS, iPadOS & macOS: Intercepts /hotspot-detect.html and /success.txt. Triggers the native CNA (Captive Network Assistant) full-screen slide-over sheet.
  • Microsoft Windows (10 / 11): Intercepts /ncsi.txt and /connecttest.txt, prompting the Windows Action Center network login banner.
Why is HTTPS Port 443 Closed (TCP RST)?
When mobile browsers (Chrome, Safari) test for captive networks, if port 443 is open with a self-signed certificate, the user sees an alarming "Your connection is not private / NET::ERR_CERT_AUTHORITY_INVALID" warning. By deliberately rejecting port 443 with TCP RST, the operating system falls back instantly to HTTP port 80 without any security warnings!

📊 Foot-Traffic Analytics & Visitor Metrics
📈 How to Download and Interpret Visitor Analytics (/stats.csv) ▼

Every time a customer connects and views your portal, PromoBeacon anonymously records connection metrics into its internal ring buffer.

Exporting Data:

Connect to the beacon's Wi-Fi and navigate to: http://192.168.4.1/stats.csv

A standard CSV file will download immediately. You can open it in Microsoft Excel, Google Sheets, or Apple Numbers.

CSV Data Fields:

  • device_id: Unique hardware identifier of your PromoBeacon.
  • client_count: Total unique smartphones detected during the current session.
  • uptime_sec: Number of seconds the beacon has been continuously running.
  • mac: Anonymized/hashed client identifier for GDPR and privacy compliance.
  • connect_count: Number of times this specific visitor returned to your location.
  • session_duration_sec: Dwell time—how long the customer stayed within wireless range.
🔒 Security Architecture & Brute-Force Lockout
🛡️ Admin Security & 5-Minute Brute-Force Lockout ▼

Because the Wi-Fi network is intentionally open so any customer can view your promotion, the administrative management interfaces (/setup, /upload, /update) are fortified with industrial security measures:

1. Dedicated Admin Password

Only authorized owners can change settings or upload files. The default password is 12345. We strongly advise changing this in /setup during deployment.

2. Automated Brute-Force Protection (Rate Limiter)

If an attacker attempts to guess passwords, the firmware enforces strict rate limiting:

  • Failed Attempt Threshold: 5 consecutive incorrect passwords.
  • Security Response: The server issues an HTTP 429 Too Many Requests and locks all administrative routes for 5 minutes.
  • Customer Portal Integrity: During the lockout, the public promotional landing page continues serving customers without any interruption.
Forgot your Admin Password?
Simply reconnect the ESP32 to your PC via USB and reflash using this web installer with the "Erase Device" option checked. It will restore factory defaults in under 30 seconds.
💻 Developer REST API & cURL Reference
⚡ HTTP Endpoints & Automated Scripting Reference ▼

PromoBeacon can be completely automated through simple HTTP requests while connected to its Wi-Fi network:

Endpoint Method Auth Header Description
/ GET None Serves the active promotional landing page.
/assets/{filename} GET None Streams static assets (PDFs, images, CSS) from BigStorage.
/setup POST X-Admin-Pwd Updates SSID, Promo Title, Country Code, and Admin Password.
/upload?name={file} POST X-Admin-Pwd Binary streaming upload directly into SPIFFS flash.
/update POST X-Admin-Pwd Over-The-Air (OTA) firmware binary update.
/stats.csv GET None Downloads visitor analytics CSV.
/portal.json GET None RFC 8908 Captive Portal JSON status API.

Example: Change SSID via cURL:

curl -X POST "http://192.168.4.1/setup" \ -H "X-Admin-Pwd: 12345" \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "promo_text=PROMOBEACON_STORE&wifi_pwd=&admin_pwd=12345&country_code=US"
❓ Frequently Asked Questions (FAQ)
Does PromoBeacon require an internet connection, SIM card, or monthly subscription? ▼

No. PromoBeacon is 100% standalone and autonomous. It creates its own hyper-local micro-network. There are no monthly fees, no SIM cards, no cloud servers, and no external subscriptions ever required.

How many customers can connect to a single beacon simultaneously? ▼

An ESP32 AP comfortably handles 8 to 10 active concurrent connections downloading files at the exact same second. Because users typically view the menu or coupon for 30–60 seconds and disconnect, a single PromoBeacon effortlessly reaches thousands of visitors per day in busy commercial venues.

What is the effective broadcast range of the beacon? ▼

With standard PCB onboard antennas, effective range is 60 to 100 meters (200 to 320 feet) in direct line of sight, and 20 to 35 meters through indoor brick or concrete walls. Using an external SMA antenna model extends line-of-sight range beyond 150 meters.

Why does Android show "Wi-Fi has no internet access"? Is that normal? ▼

Yes, this is completely normal and expected. Modern mobile operating systems detect that PromoBeacon is a dedicated captive marketing portal without an outbound internet gateway. When prompted with "Wi-Fi has no internet access. Tap to view options", simply tap "Keep Wi-Fi connection" to browse the local digital content.

Can I place multiple PromoBeacons in the same store or venue? ▼

Yes! You can deploy a beacon cluster. For example: one beacon at the entrance broadcasting "WELCOME_COUPON", and another in the bar area broadcasting "DRINKS_MENU". To avoid RF channel congestion, configure them on non-overlapping Wi-Fi channels (Channels 1, 6, and 11).

How does Apple iPhone / iPad handle the captive popup? ▼

When an iOS device joins the beacon, Apple's Captive Network Assistant (CNA) automatically slides up from the bottom of the screen, displaying your landing page instantly in full screen without requiring the user to open Safari.
