## PromoBeacon BLE Simulator + Android App — Full End-to-End Integration Verified ✅

### Context
Using `sim_esp32_ble.py` (bless-based BLE GATT server) on the homelab666 host + physical Android phone (ZE223G6FRL) running the `com.promobeacon.manager` app (mobile_app_unified). Goal: verify the whole scan→connect→read-status→auth→config-write chain works against the simulator.

### Bugs found & fixed

1. **Simulator UUID case bug** (`sim_esp32_ble.py`)
   - Handler dicts keyed by uppercase UUIDs, but bless normalizes `str(characteristic.uuid)` to lowercase (`str(UUID(...))`).
   - Fixed: `make_server_read` / `make_server_write` / `handle_write` now `.lower()` all UUID lookups. READ/WRITE handlers fire correctly.

2. **Android app UUID case bug** (`BleClient.kt`)
   - `BleConstants.CHAR_STATUS` etc. are UPPERCASE (`1234567C-...`) but Android's `characteristic.uuid.toString()` returns lowercase (`1234567c-...`).
   - `onCharacteristicRead` `when` and `onCharacteristicChanged` `if` comparisons NEVER matched → status bytes silently discarded (console showed zeros).
   - Fixed with `.lowercase()` on both sides. Status now parses: uptime, RSSI, client count, auth bit (byte 97) all display.

3. **Advertising on Qualcomm controller (host)** — the hard one
   - bless D-Bus adv: fails `Invalid Parameters (0x0d)` (extended adv 0x0054/0x0055 rejected).
   - `btmgmt add-adv` legacy path: reports "Set Advertising complete" but `ActiveInstances: 0x00` — phone never sees the device.
   - **Working solution: raw HCI commands** via `hcitool cmd`:
     - `hcitool cmd 0x08 0x000a 00` (disable adv)
     - `hcitool cmd 0x08 0x0006 00 08 00 08 00 00 00 00 00 00 00 00 07 00` (params: 100ms interval, connectable undirected, all channels)
     - `hcitool cmd 0x08 0x0008 <len> <data>` (adv data: flags 020106 + 128-bit service UUID `1107bc9a7856341234123412341278563412`)
     - `hcitool cmd 0x08 0x0009 <len> <data>` (scan rsp: name `0c0950726f6d6f426561636f6e` = "PromoBeacon")
     - `hcitool cmd 0x08 0x000a 01` (enable adv)
   - Phone immediately saw `homelab666 / 74:C6:3B:87:06:88` at -34 dBm.
